This project intends to create a Claude agent that does the following actions:
1. Check the results of the last matchday of Liga Hypermotion.
2. Make a prediction of the next matchday based on recent events (last 5 matchdays) and general considerations (playing home or away, existence of injuries, moment of the season, etc.).
3. Make a deeper analysis for the last game of Girona FC, the result it will have in the next matchday and the probabilities to promote to Laliga.
